交叉熵常用于图像分类，是因为它与分类模型的**概率输出、最大似然估计和优化目标天然一致**。

## 1. 图像分类本质上是在估计类别概率

对于一个 (K) 类分类任务，神经网络输出 logits：

[
\mathbf z=(z_1,z_2,\ldots,z_K).
]

Softmax 将 logits 转换为概率分布：

[
p_k=\frac{\exp(z_k)}{\sum_{j=1}^{K}\exp(z_j)},
\qquad
\sum_{k=1}^{K}p_k=1.
]

真实标签通常表示为 one-hot 向量：

[
\mathbf y=(y_1,\ldots,y_K),
]

其中正确类别 (c) 满足 (y_c=1)，其他类别为 (0)。

多分类交叉熵定义为：

[
\mathcal L_{\mathrm{CE}}
========================

-\sum_{k=1}^{K}y_k\log p_k.
]

由于只有正确类别对应的 (y_c=1)，它可以简化为：

[
\mathcal L_{\mathrm{CE}}=-\log p_c.
]

因此，交叉熵直接要求模型提高**真实类别的预测概率**。

例如：

* 模型给真实类别的概率为 (0.9)：

[
-\log 0.9\approx 0.105;
]

* 模型给真实类别的概率为 (0.1)：

[
-\log 0.1\approx 2.303.
]

模型对正确类别越没有信心，损失越大。

---

## 2. 交叉熵等价于最大似然估计

假设分类标签服从类别分布：

[
y_i\sim \operatorname{Categorical}(\mathbf p_i).
]

对于样本 (i)，模型观察到真实类别 (y_i) 的似然为：

[
P(y_i\mid x_i;\theta)=p_{i,y_i}.
]

整个训练集的似然为：

[
\mathcal L(\theta)
==================

\prod_{i=1}^{N}p_{i,y_i}.
]

最大化似然等价于最大化对数似然：

[
\max_\theta
\sum_{i=1}^{N}\log p_{i,y_i}.
]

也等价于最小化负对数似然：

[
\min_\theta
-\sum_{i=1}^{N}\log p_{i,y_i}.
]

这正是交叉熵损失：

[
\mathcal L_{\mathrm{CE}}
========================

-\frac{1}{N}
\sum_{i=1}^{N}\log p_{i,y_i}.
]

所以交叉熵并不是经验上随意选择的损失，而是从分类任务的概率模型中自然推导出来的。

---

## 3. 它强烈惩罚“自信但错误”的预测

考虑真实类别为第 1 类：

[
\mathbf y=(1,0,0).
]

两组预测分别为：

[
\mathbf p^{(1)}=(0.4,0.3,0.3),
]

[
\mathbf p^{(2)}=(0.01,0.98,0.01).
]

对应损失为：

[
\mathcal L_1=-\log 0.4\approx0.916,
]

[
\mathcal L_2=-\log 0.01\approx4.605.
]

第二个模型不仅预测错误，而且极度自信，因此受到更大的惩罚。这一性质有助于模型快速纠正严重错误。

需要注意的是，这也使交叉熵对**错误标签和标签噪声**较敏感：模型可能不断尝试拟合被错误标注的样本。

---

## 4. 与 Softmax 结合后梯度非常简洁

设交叉熵为：

[
\mathcal L=-\sum_{k=1}^{K}y_k\log p_k,
]

其中：

[
p_k=\operatorname{softmax}(\mathbf z)_k.
]

损失对第 (k) 个 logit 的梯度为：

[
\frac{\partial \mathcal L}{\partial z_k}
========================================

p_k-y_k.
]

这意味着：

* 对正确类别 (c)：

[
\frac{\partial \mathcal L}{\partial z_c}=p_c-1<0,
]

梯度下降会增大 (z_c)；

* 对错误类别 (k\neq c)：

[
\frac{\partial \mathcal L}{\partial z_k}=p_k>0,
]

梯度下降会减小 (z_k)。

因此，交叉熵会直接拉高正确类别的 logit，同时压低错误类别的 logits，梯度方向与分类目标完全一致。

---

## 5. 它优化的是完整概率分布，而不只是类别编号

分类标签本身是离散类别，而不是具有数值距离的连续值。

例如类别编号：

[
\text{cat}=0,\qquad \text{dog}=1,\qquad \text{car}=2
]

并不意味着：

[
d(\text{cat},\text{car})
========================

2d(\text{cat},\text{dog}).
]

如果直接对类别编号使用均方误差，模型会错误地假设类别之间存在连续数值距离。

交叉熵则比较两个概率分布：

* 真实分布 (\mathbf y)；
* 预测分布 (\mathbf p)。

从而避免赋予类别编号不合理的数值意义。

---

## 6. 交叉熵是严格适当评分规则

从理论上看，交叉熵是一种 **strictly proper scoring rule**。其重要含义是：

> 当模型希望最小化期望交叉熵时，最优预测是输出真实的条件概率分布。

设真实条件分布为：

[
q_k=P(Y=k\mid X=x),
]

模型预测为 (p_k)。期望交叉熵是：

[
H(q,p)
======

-\sum_{k=1}^{K}q_k\log p_k.
]

它可以分解为：

[
H(q,p)
======

H(q)+D_{\mathrm{KL}}(q|p),
]

其中：

[
H(q)=-\sum_k q_k\log q_k
]

与模型预测无关，而 KL 散度满足：

[
D_{\mathrm{KL}}(q|p)\ge 0.
]

因此：

[
H(q,p)\ge H(q),
]

且等号仅在：

[
p=q
]

时成立。

这说明交叉熵不仅鼓励预测正确类别，还鼓励模型学习合理的类别概率。

---

## 7. 为什么通常比均方误差更适合分类

假设对 one-hot 标签使用均方误差：

[
\mathcal L_{\mathrm{MSE}}
=========================

\frac{1}{2}
\sum_{k=1}^{K}(p_k-y_k)^2.
]

它不是完全不能用于分类，但通常存在以下问题：

1. 它来源于高斯噪声假设，更适合连续回归；
2. 与 categorical 分布并不自然匹配；
3. 和 Softmax 组合时可能出现额外的梯度缩放；
4. 在预测非常错误时，通常不如交叉熵提供直接而有效的纠正信号。

交叉熵对 logits 的梯度直接为：

[
p_k-y_k,
]

而 MSE 还需要乘上 Softmax 的 Jacobian，因此在某些饱和区域中梯度可能更弱。

## 8. 二分类与多分类中的形式

### 二分类

模型输出正类概率 (p)，标签 (y\in{0,1})：

[
\mathcal L_{\mathrm{BCE}}
=========================

-\left[
y\log p+(1-y)\log(1-p)
\right].
]

通常与 sigmoid 搭配。

### 多分类单标签

每张图像只属于一个类别：

[
\mathcal L_{\mathrm{CE}}
========================

-\log p_y.
]

通常与 Softmax 搭配。

### 多标签分类

一张图像可能同时包含多个标签，例如“人”“汽车”“道路”。此时各标签不是互斥的，一般对每个类别分别使用二元交叉熵：

[
\mathcal L
==========

-\sum_{k=1}^{K}
\left[
y_k\log p_k+(1-y_k)\log(1-p_k)
\right].
]

此时通常使用 sigmoid，而不是 Softmax。

---

## 总结

交叉熵常用于图像分类，主要因为：

[
\boxed{
\text{分类概率建模}
+
\text{最大似然估计}
+
\text{有效梯度}
+
\text{概率分布匹配}
}
]

更具体地说，它：

* 与 Softmax 或 sigmoid 输出的概率分布自然匹配；
* 等价于分类模型的负对数似然；
* 强烈惩罚自信但错误的预测；
* 梯度形式简洁，优化方向明确；
* 不对类别编号施加虚假的数值距离；
* 在期望意义下鼓励模型逼近真实条件概率分布。

不过，标准交叉熵也可能对标签噪声、类别不均衡以及难样本过度敏感，因此实践中还会使用 label smoothing、weighted cross-entropy、focal loss 或鲁棒损失进行改进。
