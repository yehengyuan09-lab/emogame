## 原则

- 偏差评分使用 sales-blind score，排除直接销量、拥有率和平均获取花费字段。
- 销量证据单独作为验证目标，支持真实销量、估算销量、销量榜名次、上限/下限声明。
- 公开来源的榜单和社区销量数字均保留 `source_confidence`，不当作官方精确销量。

## 当前样例结论

- 2026H1 榜单样本中，李信-问心剑、瑶-大耳狗之梦、铠-东海龙王·敖光与当前评分较接近。
- 公孙离-离恨烟、貂蝉-遇见胡旋、曜-器灵·螭龙剑等出现 `sales_above_score`，说明当前评分缺少观感、手感、IP/返场、人群偏好等舆情证据。
- 赵云-龙胆只有“首日未破百万”的上限声明，属于弱销量证据，只能作为风险提示。

## ML 校准结果

命令：

```bash
python scripts/calibrate_sales_score.py \
  --write-model outputs/sales_calibration_model.json \
  --write-report outputs/sales_calibration_report.json
```

结果：

- baseline：28/32 个样本 `abs(gap) > 10`，MAE 45.844。
- calibrated：0/32 个样本 `abs(gap) > 10`，MAE 1.156。
- 单侧二项检验：`p=0.034337 < 0.10`，训练集校准目标通过。
- 最低样本量：若要求 0 个失败并以 `alpha=0.10` 检验 `p < 0.10`，至少需要 22 个样本；当前 32 个样本满足。
- leave-one-out：27/32 个样本失败，说明当前模型仍是训练集校准，不应被当作泛化能力已经达标。
